# DatalytIQs MERL Professional Pathway — Course Engineering Stage 01

This directory is the machine-readable source of truth for the DatalytIQs Monitoring, Evaluation, Research & Learning (MERL) Professional Pathway.

## Scope

Five progressive levels take a learner from beginner to expert:

1. M&E Foundations
2. Applied Monitoring & Evaluation
3. M&E Data Analytics
4. Evaluation & Impact Evaluation
5. Advanced MERL & Decision Intelligence

The pathway is competency-based and practice-led. Every competency must be demonstrated through an exercise, lab, assignment, case study, project or capstone artifact.

## Files

- `curriculum.manifest.yaml` — programme, levels, modules, lessons, outcomes and progression rules.
- `competencies.json` — competency taxonomy and mastery thresholds.
- `prerequisite-graph.json` — explicit prerequisite and unlock graph.
- `assessments-rubrics.json` — assessments, weights, pass rules and reusable rubrics.
- `datasets-cases.json` — datasets and case-study inventory.
- `tutor-lms-map.json` — Tutor LMS representation and completion logic.
- `analytics-lab-map.json` — Analytics Lab activities, expected outputs and execution requirements.

## ID convention

- Programme: `MERL-PRO`
- Level: `MERL-L1` … `MERL-L5`
- Module: `MERL-L{n}-M{nn}`
- Lesson: `MERL-L{n}-M{nn}-L{nn}`
- Competency: `MERL-COMP-{DOMAIN}-{nnn}`
- Exercise: `MERL-EX-{nnn}`
- Dataset: `MERL-DS-{nnn}`
- Case study: `MERL-CASE-{nnn}`
- Assessment: `MERL-ASMT-{nnn}`
- Rubric: `MERL-RUB-{nnn}`

## Pedagogy

`LEARN -> OBSERVE -> PRACTISE -> ANALYSE -> INTERPRET -> SUBMIT -> FEEDBACK -> APPLY`

## Credential rule

A learner cannot earn a level credential by quiz score alone. The learner must meet the overall pass mark, minimum competency threshold, mandatory practical-artifact requirements and level-project gate.

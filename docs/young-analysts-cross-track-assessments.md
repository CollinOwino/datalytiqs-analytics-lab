# Young Analysts — Cross-Track Applied Assessment Bank

## Common evidence standard
Every capstone produces: question/purpose, artefact, test or quality checks, interpretation, limitation, reflection. Review each dimension 0–3: method/correctness; evidence/testing; reasoning/communication; responsible practice. The provisional competency rule remains 8/12 with no zero in responsible practice; validate during pilots before consequential use.

## Excel & Data Literacy
1. **Messy Register Repair (EDL-02):** clean a supplied synthetic attendance table. Submit cleaned data plus change log. Tests: row count reconciliation, category frequencies before/after, duplicate decision.
2. **Formula Audit (EDL-03):** build a workbook that calculates attendance rates and flags low attendance. Submit formulas and independent hand-checks for two rows.
3. **Chart Choice Challenge (EDL-05):** create two charts answering different questions. Explain why each chart type fits and identify one misleading alternative.
4. **Dashboard Brief (EDL-06):** one-page dashboard with 3–5 indicators, two charts, source note, denominator definitions and two bounded findings.

## Statistics
1. **Centre vs Outlier (STA-03):** compare mean/median before and after an extreme value. Explain which summary is more informative and why.
2. **Fair Rate Comparison (STA-04):** compare participation across unequal groups using rates, not raw counts; show calculations.
3. **Sampling Critique (STA-05):** rank three sampling plans by likely bias mechanisms, then redesign one. Do not infer representativeness merely from sample size.
4. **Evidence Claim Clinic (STA-06):** rewrite five overclaimed statements into descriptions supported by the supplied evidence.

## Research & Survey Skills
1. **Question-to-Measure Matrix (RES-02):** research question → concept → variable → operational definition → response format → quality risk.
2. **Questionnaire Repair (RES-03):** diagnose leading, double-barrelled, ambiguous and unbalanced questions; submit corrected instrument and rationale.
3. **Sampling Plan (RES-04):** define population, frame, selection procedure, inclusion rule and likely coverage limitations.
4. **Pilot Revision Log (RES-06):** use synthetic pilot responses to identify instrument defects and document revision decisions.

## AI Literacy
1. **Claim Verification Audit (AIL-03):** inspect an intentionally flawed AI response. Classify claims as verified, unsupported, contradicted or opinion; record verification evidence.
2. **Prompt Experiment (AIL-04):** hold task constant while changing one framing variable. Compare outputs without treating either as ground truth.
3. **Privacy Triage (AIL-05):** classify sample information as suitable, redact/transform first, or do not enter; explain purpose/data-minimisation reasoning.
4. **Human-in-the-Loop Product (AIL-06):** create a bounded AI-assisted evidence product. Submit prompt log, verification log, human edits, sources used, limitations and disclosure.

## Data Analytics for Teens
1. **Analysis Charter (DAT-01):** decision, user, question, unit of analysis, measures, data needed, success criteria and non-goals.
2. **Cleaning & QA Log (DAT-02):** profile supplied synthetic data, document defects and reconcile row counts and derived fields.
3. **Exploratory Evidence Pack (DAT-03):** 3–5 useful summaries/charts, each tied to a question; include one pattern rejected as artefact or irrelevant.
4. **Comparison Analysis (DAT-04):** compare participation/resource measures using appropriate denominators; separate calculation from interpretation.
5. **Limitations Register (DAT-05):** identify missingness, selection, measurement, confounding/causal and generalisability risks; state likely direction where defensible.
6. **Decision Brief (DAT-06):** one page: question, method, 3 key findings, uncertainty/limitations, proportionate recommendation and next evidence need.

## Test design standard
Automated or structured checks should test the intended construct. Prefer expected-vs-actual calculations, boundary cases, reconciliation and interpretation over brittle checks for exact wording. Free-text reasoning requires human/rubric review unless a validated scoring mechanism exists.

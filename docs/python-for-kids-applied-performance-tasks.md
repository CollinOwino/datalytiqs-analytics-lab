# Python for Kids — Applied Performance Tasks

These tasks complement lesson checks. They generate evidence of competency, not merely completion.

## Module 01 — Algorithm Card
Create a four-step algorithm for a familiar, non-sensitive task and implement it as ordered Python output. Deliberately swap two steps, explain why the result is weaker, then correct it.
Evidence: original algorithm, altered version, corrected version, short explanation.

## Module 02 — Transparent Score Calculator
Build a calculator that combines three numeric values and labels the result clearly. Independently calculate one expected result before running the code.
Tests: normal values and a zero value. Evidence: code plus expected/actual table.

## Module 03 — Safe Idea Generator
Ask two non-personal questions and produce a useful combined response.
Tests: two different safe input pairs. Evidence: code, outputs, and one piece of information the program deliberately does not collect.

## Module 04 — Decision Boundary Lab
Build a three-band decision rule. Write expected outcomes for values immediately below, at and above each important boundary before running it.
Evidence: decision table, code, expected/actual results.

## Module 05 — Loop Safety Challenge
Create one for-loop task and one terminating while-loop task. Predict iteration counts and explain why the while loop must stop.
Evidence: code, predicted/actual counts, termination explanation.

## Module 06 — Mini Activity Dataset
Create a list of at least five non-personal numeric observations. Report count, total, minimum and maximum; change one value and explain which summaries change.
Evidence: code plus before/after summary.

## Module 07 — Function Test Bench
Create a function that transforms a numeric input and returns a result. Test at least three inputs, including a simple boundary case such as zero where meaningful.
Evidence: function, test table, explanation of why the tests were chosen.

## Module 08 — Small Game, Complete Test
Create a choice-based game with at least two valid routes, score state and an invalid-input response.
Tests: every valid route plus one invalid choice. Evidence: code, route test table, one improvement based on testing.

## Module 09 — Responsible Data Story
Use 5–8 safe observations to answer a simple question. Calculate at least two summaries and write a finding that stays within the evidence.
Evidence: dataset, calculations, finding, one limitation and one statement the data cannot support.

## Module 10 — Capstone
Plan and build a small original Python solution.
Required submission: problem/purpose; intended user; inputs and outputs; safety/data-minimisation note; code; at least three acceptance tests with expected and actual results; one debugging/change-log entry; explanation of an important design decision; limitation; next improvement.

## Applied-task rubric (12 marks)
- Method & correctness: 0–3
- Evidence & testing: 0–3
- Reasoning & communication: 0–3
- Responsible practice: 0–3

Provisional competency rule: 8/12 or higher and no zero in Responsible practice. Pilot data should be used to review this threshold before consequential use.

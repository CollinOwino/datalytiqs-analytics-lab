# Module 02 — Project and Programme Logic

## L01 — Projects, Programmes and Results
**Outcome:** Distinguish interventions, implementation processes and results. **Bloom:** Understand. **Time:** 45 min.

A project is a time-bound intervention designed to produce specified results with defined resources. A programme normally coordinates multiple related interventions toward broader outcomes. M&E begins by making the intervention logic explicit: what resources are invested, what is done, what is produced, what changes for participants, and what longer-term condition is expected to improve.

Results are changes attributable or contributable to an intervention, not merely tasks completed. 'Conduct training' is an activity; '1,000 participants trained to standard' is an output; 'participants apply market-relevant skills' is an outcome.

### Guided exercise
Rewrite ten activity statements as results statements. For each, identify whether the result is an output, outcome or impact.

## L02 — Inputs, Activities, Outputs, Outcomes and Impact
**Outcome:** Correctly classify statements across the results chain. **Bloom:** Apply. **Time:** 55 min.

**Inputs** are resources: money, staff, equipment, partnerships and time. **Activities** are actions using those resources. **Outputs** are the immediate products/services delivered. **Outcomes** are changes in behaviour, practice, access, performance or condition that follow. **Impact** is the higher-order, longer-term change to which the intervention contributes.

### Worked example
Budget + trainers → deliver technical and employability training → certified graduates → increased job-search competence and employment → improved youth livelihoods.

A results chain should be plausible but never treated as automatic. Each arrow embeds assumptions.

### Case activity
Using the Youth Employment Programme brief, classify 20 supplied statements. Flag statements that mix two levels or are too vague to measure.

## L03 — Build and Test a Results Chain
**Outcome:** Construct and critically test a complete causal results chain. **Bloom:** Analyse. **Time:** 70 min.

### Lab procedure
1. State the development problem and target population.
2. Identify critical inputs and activities.
3. Express outputs as deliverables, not actions.
4. Express outcomes as changes in people, institutions or systems.
5. State the intended impact.
6. Test each arrow with the question: 'Why should this lead to the next result?'
7. Record the assumption behind each transition.

### Professional standard
A strong chain is specific enough to monitor, causal enough to evaluate, and simple enough for decision-makers to understand.

### Professional output
Submit a one-page results chain plus a causal-assumption table.

### Completion condition
Every result has one level only; all arrows have an explicit rationale; no activity is mislabeled as an outcome.

# DatalytIQs MERL Professional Pathway — Course Engineering Stage 01

This directory is the machine-readable source of truth for the Monitoring, Evaluation, Research & Learning Professional Pathway.

## Architecture

The pathway progresses from M&E foundations through applied M&E, analytics, evaluation and expert MERL/decision intelligence. It is competency-based and evidence-gated.

Ecosystem model: **Academy → Learn; Analytics Lab → Practise & Execute; Community → Collaborate & Connect; Professional Services → Apply.**

## Files

- `curriculum.manifest.yaml` — canonical programme/level/module architecture
- `competencies.json` — competency registry across Knowledge, Application and Professional Practice
- `prerequisite-graph.json` — progression and unlock graph
- `datasets.manifest.json` — synthetic practice datasets to generate
- `case-studies.manifest.json` — recurring applied cases
- `assessments.json` — weighting, gates and completion rules
- `rubrics.json` — common professional competency rubric
- `tutor-lms-map.json` — Tutor LMS representation/import contract
- `analytics-lab-map.json` — computational lab integration contract

## Non-negotiable instructional rule

No competency without practice; no level without demonstrated evidence; no expert credential without an integrated professional capstone.

## Stage 02 build target

Generate the full lesson registry with outcomes, Bloom progression, durations, exercises, resources, assessments and completion conditions; generate synthetic datasets; then build Level 1 production content and Tutor LMS import payloads.
